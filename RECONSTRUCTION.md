# AI-Cyber Reconstruction

This repository is undergoing evidence-driven forensic reconstruction.

The original phase-generated Python files are preserved as legacy evidence until
the reconstructed package passes compilation, import, structural, integration,
regression, and end-to-end gates.

## Reconstruction order

1. forensic baseline
2. AST dependency extraction
3. canonicalization
4. responsibility/phase sharding
5. import and structural verification
6. regression verification
7. compatibility surface
8. legacy retirement only after evidence

No implementation is considered working merely because it imports.
